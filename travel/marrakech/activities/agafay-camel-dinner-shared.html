Self-drive DIY

  • Route south toward Amizmiz/N8; GPS to specific camp.
  • Paved until last 2–5 km (graded dirt — sedan usually OK daytime).
  • Evening dinner DIY: possible but dark return — organized transfer usually better for sunset dinner.
  • Daytime DIY fuel ~4–8 L RT ≈ 60–120 MAD (~CAD 9–18) + any camp day-pass (unverified per camp).

Practical notes

  • Agafay is a stone desert, not Sahara dunes.
  • Dec–Jan evenings chilly — warm jacket, closed shoes. Towel if using pool.
  • Duration listed 5h30; reviewers note can run longer (one ~9 h door-to-door).
  • NYE night: expect surcharges or sell-outs — book early or choose another evening.
